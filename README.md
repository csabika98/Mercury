## 🚀 About Codename: Mercury

**Mercury** is a versatile Content Management System (CMS) designed to give you full control over your content. Whether you want to create a blog, forum, e-commerce site, or any other type of content platform, Mercury provides the tools you need to bring your vision to life.

---

## 🛠️ Development Status

Mercury is currently under active development and is in its early stages. We are continually adding new features and improvements to enhance its functionality and usability.

## 🛠️ Technologies Used

Mercury is built using the following technologies:

- **Laravel 8**: A powerful PHP framework for building modern web applications.
- **MySQL**: A reliable and robust database management system.
- **React**: A JavaScript library for building dynamic and responsive user interfaces.
